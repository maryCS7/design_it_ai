# DesignIt AI

**DesignIt AI** is an interactive tool that uses OpenAI’s DALL·E API and Gradio to generate visuals from text prompts.

This mini-project demonstrates how generative AI can streamline design workflows, especially for creative agencies building assets for digital campaigns.

## Features
- Text-to-image generation
- Easy-to-use Gradio interface
- Showcase of AI-enhanced creative design

## Tools Used
- OpenAI API (DALL·E)
- Gradio
- Python
